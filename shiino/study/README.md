# shiino_勉強記録

React + Vite で作った、科目ごとの勉強時間を記録するアプリ。

## 起動方法

```bash
npm install   # 初回のみ
npm run dev   # 表示されたURLを開く
```

他のアプリと同時に動かすときは `npm run dev -- --port 5176` のようにポートを指定する。

## 画面の流れ

```
タイトル ──START──> メニュー ──アイコンを押す──> 機能の画面
                       ^                            |
                       └────「メニューに戻る」/ Esc ──┘
```

メニューに並ぶアイコンの順番と説明は `lib/features.js` で決めている。

各ページは、その機能を先頭に置き、続けて「そこで一緒に見たくなるもの」をそえる。

| ページ | 並べるカード |
| --- | --- |
| 計測 | 計測 → 今のペース → 追加した記録 |
| 合計 | 合計 → マイルストーン |
| 記録 | 記録 → 合計 |
| マイルストーン | マイルストーン → 記録 |
| ボス戦 | ボス戦 → 今のペース → 追加した記録 |
| 科目 | 科目 → 科目別の累計 |
| 手入力 | 手入力 → 追加した記録 → 今のペース |

合計 → マイルストーン → 記録 → 合計 と一巡するように組んであり、
同じ組み合わせのページができないようにしている。

どの画面も横幅は752pxでそろえ、中身は画面の上下中央に置く。
中身が画面より高いときは、そのまま下に伸びて普通にスクロールできる。

## できること

- **タイトル画面**: 開くと最初に出る。STARTまたはEnterでメニューへ。
  今日の勉強・到達段階・ボス戦の達成度の3枚を出して、続きから始められるようにする。
  計測中は、科目名と経過時間の帯を1秒ごとに更新して出す。
  3枚とも「値・帯・補足」の同じ形にそろえてある（今日＝今週に占める割合、
  到達段階＝次の段階までの進み具合、ボス戦＝達成度）
- **メニュー**: 機能ごとのアイコンを1行3つ・3行（3＋3＋1）で並べる。押すとその機能の画面に移る。
  画面が狭いか低いときは、タイルとアイコンを小さくして1行4つに詰める
  （3行だと入りきらずスクロールしてしまうため）。
  計測したまま別の画面に移れるので、計測中は経過時間のバッジを1秒ごとに更新して出す。
  ボス戦に挑んでいるときは、開かなくても分かるように達成度のバッジを出す。
  数字キー（1〜7）でも選べる
- **計測**: 科目を選んで開始／一時停止／停止。停止した時点で記録に残り、すぐ下の「追加した記録」に出る。
  8時間を超える計測は、止め忘れの可能性があるので記録するか破棄するかを確認する
- **合計**: 今日／今週／全期間で切り替え。科目別の内訳と直近7日を棒グラフで表示
- **記録**: 日付ごとにまとめて表示。1件ずつ編集（科目・日付・時間）・削除できる
- **マイルストーン**: 累計の勉強時間に応じて、9段階を順に到達していく
- **ボス戦**: 試験日と目標時間を決めて、勉強したぶんだけHPを削る。期限や科目を分けて何体でも同時に挑める
- **科目**: 追加・削除。色を8色から選べる。**削除しても記録は消えない**（「（削除された科目）」として残る）
- **手入力**: 計測し忘れた分を、日付と時間を指定して後から追加。追加したものはすぐ下に出る
- **追加した記録**: 計測・手入力・ボス戦の画面にそえる直近5件。今足したぶんを色付きで示す。
  その場で削除もできるので、押し間違えたらすぐ取り消せる
- **今のペース**: 計測・ボス戦・手入力の画面にそえる、今日／今週／1日あたり（直近7日）。
  ボス戦の「1日あたり◯◯必要」と並ぶので、間に合っているかがその場で分かる
- **科目別の累計**: 科目の画面にそえる、科目ごとの全期間の合計。
  棒はいちばん多い科目を基準にする（合計に対する割合より、科目どうしの差が見やすいため）

## マイルストーン

累計の勉強時間で到達する段階が決まる。段階は9つ。

| 段階 | 必要な累計 | | 段階 | 必要な累計 |
| --- | --- | --- | --- | --- |
| スタート | 0時間 | | 上級 | 80時間 |
| 入門 | 5時間 | | 熟練 | 150時間 |
| 初級 | 15時間 | | 達人 | 250時間 |
| 中級 | 40時間 | | 名人 | 400時間 |
| | | | 極み | 600時間 |

目盛りは等間隔で描き、現在位置のマークだけが区間の進み具合に応じて動く
（時間どおりの間隔にすると、最初のほうが潰れて読めなくなるため）。

## ボス戦

試験日・目標時間・対象科目を決めて挑戦する。

達成度（`bossProgress`）はタイトル画面とメニューの両方に出す。挑戦中は `35%` のような数字、
決着後は `撃破` / `期限切れ` と言葉で出し、期限切れだけ赤くする。

- **挑戦したあとの勉強だけがダメージになる**（挑戦前に済ませた分は入らない）
- 対象科目を選ぶと、その科目の勉強だけが効く（「すべての科目」も選べる）
- 残りHPと、期限に間に合わせるために必要な「1日あたりの時間」を表示
- 目標を達成すると**撃破**、達成せずに期限を過ぎると**期限切れ**

## 記録の保存先

保存先はブラウザの localStorage だけ。次のどれかで消えるので注意する。

- ブラウザの「閲覧データを削除」
- 別のPC・別のブラウザで開く
- シークレットウィンドウで使う

書き出し・読み込みの機能は持っていない。

## 設計のメモ

- 記録は `{ id, subjectId, seconds, startedAt }` の形。科目名ではなく **id で参照**しているので、
  科目名を変えても過去の記録が壊れない。
- 集計は保存せず、記録から毎回計算する。合計値を別に持つと、記録を消したときにずれるため。
- 日付は `YYYY-MM-DD` の文字列で扱う。この形式なら文字列のまま大小比較でき、
  「今週かどうか」の判定が単純になる（`toISOString()` はUTCになるので使っていない）。
- 科目を削除すると、その科目の記録もまとめて消える。消える件数を確認ダイアログで伝えてから実行する。
- 今どの画面かは `App.jsx` の `screen` 1つで持つ。`"title"` → `"menu"` → 機能のキー、と入る値が変わる。
  画面ごとに別のフラグを持つと組み合わせが増えるので、1つの値で表している。
- 記録や計測中の状態は画面をまたいで `App.jsx` が持ち続ける。
  そのため、計測を始めたまま別の機能を見に行っても計測は止まらない。
- 経過時間は `App.jsx` で1秒ごとに数え直し、計測画面・メニュー・タイトル画面に同じ値を渡す。
  画面ごとにタイマーを持たないので、どこで見ても同じ秒数になる。
  計測中の状態は localStorage に残るため、閉じて開き直すと**タイトル画面から続きの時間が見える**。
- **科目を消しても記録は消さない**。積み上げた時間まで失われるほうが困るため。
  記録は科目名ではなく id を持っているので、科目がいなくなった記録は
  「（削除された科目）」と表示されるだけで、集計にはそのまま入る。
- 計測中の状態は `{ subjectId, startedAt, accumulated, since }`。
  `accumulated` が止めていたぶんを除いた確定秒数、`since` が今動いている区間の開始時刻
  （一時停止中は null）。経過時間は `accumulated + (now - since)` で出す。
  古い形（`accumulated`/`since` が無い）は `loadRunning` が読み替えるので、
  更新前に計測していても止まらない。
- ボスは配列で持つ。1件だけだったころの `study.boss` は `loadBosses` が読んで移し替える。
- 記録の追加は `App.jsx` の `addRecord` 1か所に集めてあり、そこで直前のidも覚える。
  計測でも手入力でも同じ場所を通るので、どちらから足しても同じように色が付く。
- 「追加した記録」は日付順ではなく**追加した順**で新しいほうから並べる。
  日付順にすると、過去の日付を手入力したときに、今足したぶんが下に埋もれて見えなくなるため。
