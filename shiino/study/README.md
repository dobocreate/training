# STUDY LOG（勉強記録）

科目ごとの勉強時間を計測して、**遅れている科目に時間を回す** ためのアプリ。
React + Vite で作っていて、データはブラウザの localStorage に保存する。サーバーには何も送らない。

---

```bash
npm install   # 初回のみ
npm run dev   # 表示されたURL（http://localhost:5173）を開く
```

## 2. このアプリの考え方

勉強時間を積み上げるだけだと、**得意な科目ばかりやってしまう**。
そこで科目ごとに「どれだけ進んだか」を数字にして、いちばん進んでいる科目に他が追いつくよう勧める。

数字は2つの材料から作る。

```
  自信（自分で付ける 0〜100%）────┐
                                  ├─ 重みで混ぜる ──→ 進捗度（0〜100%）
  やることの達成率（チェック率）──┘
```

そして進捗度をくらべて、次にやる科目を決める。

```
  進捗度がいちばん高い科目 ＝ 先頭
        ↓
  他の科目は「先頭まであと ○%」
        ↓
  差が大きい科目から勧める（嫌いな科目は少し先に回す）
```

## 3. 用語

仕様を読むうえで、この5つの区別がいちばん大事。

| 用語 | 意味 | 誰が決めるか |
| --- | --- | --- |
| **自信** | その科目にどれくらい自信があるかの **自己申告**。0〜100% | 本人が付ける（自信チェック・自信を直す・科目登録） |
| **やることの達成率** | チェック済みの項目 ÷ 全項目。0〜100% | やることリストのチェック状況から自動 |
| **進捗度** | 自信と達成率を **重みで混ぜた数字**。画面に出るのはほぼこれ | 自動計算（重みだけ本人が決める） |
| **好き嫌い** | ★1〜5。★1 大嫌い / ★3 ふつう / ★5 大好き | 本人が付ける |
| **先頭** | 進捗度がいちばん高い科目。同点なら一覧で先にあるほう | 自動 |

- 入力欄に出るのは常に **自信**（自己申告そのもの）
- 一覧・グラフ・おすすめの判断に使うのは常に **進捗度**（混ぜたあと）

## 4. 画面の流れ

```
タイトル ──START / Enter / Space──> メニュー ──タイルを押す──> 各機能の画面
                                      ^                            |
                                      └──「メニューに戻る」/ Esc ──┘
```

| 画面 | 中身 |
| --- | --- |
| **タイトル** | いちばん近いテストまでのカウントダウン・科目ごとの進捗度。計測中なら経過時間も出る |
| **メニュー** | 5つのタイル（計測・合計・やること・進捗度・科目）。PCでは3つ＋2つ、スマホ縦では2列（余った最後の1つは横長）、スマホ横でも3つ＋2つのまま、タイルを薄くして収める。計測中は経過時間がバッジで出る |
| **各機能** | 下の「5. 機能の仕様」のとおり |

各機能の画面は、その機能のカードを先頭に置き、操作を助ける小さいカードをそえる。

| 画面 | 並べるカード |
| --- | --- |
| 計測 | （自信チェック）→ 計測 → 今のペース |
| 合計 | 合計 → 記録 |
| やること | やることチェックリスト |
| 進捗度 | 進捗度 → 自信を直す → 進捗度の計算 |
| 科目 | 科目 → テストの予定 |

## 5. 機能の仕様

### 5.1 計測

科目を選んで **開始** し、**一時停止** で休憩を数え、**停止して記録** で記録に残す。

| 操作 | 動き |
| --- | --- |
| 開始 | 選んでいる科目の計測を始める。科目が0件なら押せない |
| 一時停止 | 時計が止まり、そのあいだは **休憩** として数える |
| 再開 | 休憩を確定して、勉強の計測に戻す |
| 停止して記録 | 記録を1件作り、続けて「自信チェック」を出す |

- 計測中に別の画面へ移っても止まらない。**ブラウザを閉じても続きから再開できる**
- 計測中は科目を変えられない（途中で付け替えると記録が曖昧になるため）
- 休憩の時間は記録に残るが、**勉強時間の合計には入れない**
- 1秒未満の計測は誤操作とみなして記録しない
- 科目のチップは **やるべき順**（進捗度画面の「次はこれ」と同じ順）に並び、進捗度が付く。開いたときはその先頭の科目が選ばれている

#### 自信チェック（停止直後）

- 停止すると、計測パネルの上に「自信チェック」が出る。スライダー（5%きざみ）か数字で 0〜100% を付けて保存する
- **閉じるボタンは無い**。保存するまで出たままになる
- 前回の値からの差を横に添える（「前は 40% → +10 アップ！」）
- その科目に未チェックの「やること」があれば、**3つまで**「今日できるようになった？」と並ぶ。チェックして保存すると、やることリストにも反映される
- 保存前にリロードすると、この問いかけは消える（記録はすでに残っている）

### 5.2 合計

- **今日 / 今週 / 全期間** で切り替える（初期表示は今日。今週は月曜はじまり）
- 科目別の内訳と、直近7日の棒グラフを出す。休憩の合計も横に添える
- その下に **記録** の一覧。日付ごとにまとめ、1件ずつ **科目・日付・時間** を編集でき、削除もできる
- 編集で1日の合計が24時間を超えるときは、保存せずにエラー文を出す

### 5.3 やること

科目ごとのチェックリスト。ここのチェック率が進捗度の材料になる。

- 「二次方程式を解けるようにする」のように、**1つの単元・1つの技能を1項目**にする（画面には書かない）
- **科目ごとに1枚のカード**。見出しに「3 / 10 できた」、その下に科目色の棒、項目は **これから → できた** の順に分けて並べ、追加欄は一番下
- チェックしてから **30日以上** 経った項目は薄く出す（まだできるか見直すきっかけ）
- 科目を削除すると、その科目のリストも消える（確認のときに件数を出す）

### 5.4 進捗度

#### 進捗度の計算

```
進捗度 = 自信 × 自信の重み + やることの達成率 × （100 − 自信の重み）
```

- 重みは **進捗度の計算** のカードのスライダーで決める（10%きざみ／初期値 50%）
- やることリストが無い科目は、**自信そのまま**
- 項目が5個未満の科目は、達成率の重みを **（項目数 ÷ 5）倍** に弱める。少ない項目で数字が振れすぎないため

例（重み 50% のとき）

| 科目 | 自信 | やること | 達成率 | 進捗度 |
| --- | --- | --- | --- | --- |
| 数学 | 60% | 10項目中3つ | 30% | `60×0.5 + 30×0.5` = **45%** |
| 英語 | 60% | 3項目中1つ | 33% | 項目が少ないので達成率の重みは 0.5×(3÷5)=0.3 → `60×0.7 + 33×0.3` = **52%** |
| 理科 | 60% | なし | − | **60%**（自信のまま） |

混ぜた進捗度は保存せず、毎回その場で計算する。重みを変えると全科目の進捗度がすぐ変わる。

#### 進捗度カード（追いつきの表示）

- 科目を **進捗度の高い順** に並べ、棒で出す
- 先頭の位置に **青い実線**、100%（目標）の位置に **青い点線** を引く
- 先頭までの差を「あと ○%」で添える。遅れている科目の % は黄色
- やることリストがある科目には「やること 3 / 10」を添える

#### 次はこれ（おすすめの選び方）

差があるときは **優先度** の高い科目を1つ選ぶ。

```
優先度 ＝ 先頭との差（%） ＋ 好き嫌いのぶん
```

| ★ | 足し引き |
| --- | --- |
| ★1 大嫌い | +20 |
| ★2 嫌い | +10 |
| ★3 ふつう | 0 |
| ★4 好き | −10 |
| ★5 大好き | −20 |

「好きで進んでいない」より「**嫌いで進んでいない**」を先に勧めるため。

同じ優先度なら、直近7日でいちばん触っていない科目 → 一覧の並び順、の順で決める。

例（先頭が 80% のとき）

| 科目 | 進捗度 | 差 | ★ | 優先度 |
| --- | --- | --- | --- | --- |
| 英語 | 50% | 30 | ★2 嫌い | 30 + 10 = **40** ← これを勧める |
| 数学 | 45% | 35 | ★5 大好き | 35 − 20 = 15 |

差が大きいのは数学だが、嫌いな英語を先に勧める。

#### モードの切り替え

| 状態 | 条件 | 勧め方 |
| --- | --- | --- |
| ふつう | 最大の差が 5% より大きい | 優先度（差 ± 好き嫌い）が高い順 |
| 全体を上げる | 上に加えて、進捗度の平均が **80% 以上** | 好き嫌いの足し引きをやめ、**差だけ** で決める |
| 横並び | 最大の差が **5% 以内** | 差で選べないので、**★の少ない（嫌いな）科目** から順に上げる |

- ★2以下の科目を勧めるときは「嫌いな ○○」と文言が変わる
- 横並びのときは「横並び！100% を目指して、まずは嫌いな ○○ から！」。全科目 100% なら好きにやるよう促す
- 横並びのときの「あと ○%」は、先頭ではなく **100% までの残り**
- しきい値は `lib/confidence.js` の `LEVEL_THRESHOLD`（5）と `RAISE_ALL_FROM`（80）

#### 同じ画面の下2つのカード

- **自信を直す**: 科目ごとに自信（自己申告）と好き嫌いの星を直せる
- **進捗度の計算**: 自信 ←→ リスト のスライダーで重みを決める。今の式と、どちら寄りかの一言を出す

### 5.5 科目

- 追加・削除できる。色は8色から選ぶ
- 登録するときに **名前・自信・好き嫌い・色** を決める。自信はスライダーか数字で 0〜100%（ふつうは低めから始める）
- 一覧の数字と星を直せば、自信と好き嫌いをあとから手直しできる
- 自信の付け直しは履歴に残る（`study.confidenceLog`）
- **削除しても記録は消えない**。「（削除された科目）」として一覧と集計に残る

#### テストの予定（科目の下のカード）

- 名前・日付・科目（決めなくてもよい）で登録する。日付は今日以降
- 一覧は日付の近い順。「あと ○日」「今日！」「終了」を添え、3日以内は赤、終わったものは薄く出す
- 終わって **30日以上** 経った予定は、次に開いたときに消える
- 科目を削除しても予定は残る（科目名の表示だけ無くなる）

### 5.6 タイトル画面

- **いちばん近いテスト** を「あと ○日」と大きく出す（当日は「今日！」、3日以内は赤）。ほかにも予定があれば「ほか ○件」を添える。予定が無ければ出ない
- 計測中なら、赤い点と経過時間
- 科目ごとの **進捗度** を高い順に、棒と % と好き嫌いの星で出す。遅れている科目の % は黄色
- 先頭の位置に青い実線、100% の位置に青い点線
- 横並びのときだけ「横並び！100% を目指そう。まずは ○○ から」を添える（差があるときは棒と線で分かるので文は出さない）

### 5.7 タブのアイコンと名前

- タブの名前は今いる画面に合わせて変わる。タイトル画面は「STUDY LOG」、メニューは「メニュー | STUDY LOG」、各機能は「計測 | STUDY LOG」のように画面名を前に付ける
- 同じコーヒーカップを、タイトル画面・メニュー・各機能の画面の「STUDY LOG」の左にも置く（`CoffeeCup.jsx`）。タブと画面で同じ絵が同じ量で満ちる
- ブラウザのタブに出るアイコンは、**今日の勉強時間に合わせて描き替わる**。茶色の枠の白地に茶色のカップで、コーヒーが溜まっていき、1時間（`DAILY_GOAL_SECONDS`）で満タンになって湯気が立つ
- 計測中のぶんも足すので、計測しているあいだはコーヒーが少しずつ増える（1% きざみで描き直す）
- canvas で PNG を描いて `<link rel="icon">` に差し込む。JavaScript が動く前は `public/favicon.svg`（0% の絵）が出る

## 6. 全体にかかるルール

| ルール | 中身 |
| --- | --- |
| **1日の上限は24時間** | 同じ日（`startedAt` の日付）の合計が24時間を超える記録は入れられない。計測の停止は残りぶんに切り詰めて alert で伝える。手入力・編集はエラー文をフォームに出す |
| **8時間を超える計測は確認** | 止め忘れの可能性があるので、記録するか破棄するかを確認する |
| **休憩は集計に入れない** | 記録には残すが、勉強時間の合計には足さない |
| **科目を消しても記録は消さない** | 積み上げた時間まで失うほうが困るため |
| **集計は保存しない** | 記録から毎回計算する。記録を消してもずれない |

## 7. データ

### 保存先と注意

保存先はブラウザの localStorage だけ。サーバーには何も送らない。
次のどれかで **データは消える**。

- ブラウザの「閲覧データを削除」
- 別のPC・別のブラウザで開く
- シークレットウィンドウで使う

書き出し・読み込みの機能は持っていない。

### データの形

| 種類 | 形 | メモ |
| --- | --- | --- |
| 科目 | `{ id, name, color, confidence, feeling }` | `confidence` は 0〜100 の整数（＝自信）。`feeling` は 1〜5（★の数）。無ければ自信 0・★3 を補う |
| 記録 | `{ id, subjectId, seconds, breakSeconds, startedAt }` | 科目は名前ではなく **id で参照**。`breakSeconds` が無い古い記録は 0 として扱う |
| 計測中 | `{ subjectId, startedAt, accumulated, since, breakAccumulated, pausedAt }` | 下の表を参照 |
| 自信の履歴 | `{ id, subjectId, value, at }` | 科目には今の値だけを持ち、推移はこちらで追う |
| やること | `{ id, subjectId, text, done, doneAt, createdAt }` | `doneAt` は最後にチェックした時刻（外すと null） |
| 設定 | `{ selfWeight }` | 自信の重み（0〜100） |
| テストの予定 | `{ id, name, date, subjectId, createdAt }` | `date` は `YYYY-MM-DD`。`subjectId` は空文字なら科目なし |

**計測中の状態の読み方**

| 値 | 意味 |
| --- | --- |
| 勉強の秒数 | `accumulated + (now − since)`。一時停止で `accumulated` に畳み、`since` を null に |
| 休憩の秒数 | `breakAccumulated + (now − pausedAt)`。再開で `breakAccumulated` に畳み、`pausedAt` を null に |
| 不変条件 | `since` と `pausedAt` は必ずどちらか片方だけが入る |

日付は `YYYY-MM-DD` の文字列。文字列のまま大小比較できるので「今週かどうか」の判定が単純になる（`toISOString()` はUTCになるので使わない）。

### localStorage のキー

| キー | 中身 |
| --- | --- |
| `study.subjects` | 科目の一覧 |
| `study.records` | 記録の一覧 |
| `study.running` | 計測中の状態 |
| `study.confidenceLog` | 自信の付け直しの履歴 |
| `study.skills` | やることチェックリスト |
| `study.settings` | 設定（自信の重み） |
| `study.exams` | テストの予定 |

古い形式（`study.boss` / `study.bosses`、`accumulated` の無い計測状態）は読み込み時に `storage.js` が読み替える。

## 9. 設計の判断

**画面まわり**

- 今どの画面かは `App.jsx` の `screen` 1つで持つ。`"title"` → `"menu"` → 機能のキー、と値が変わる
- メニューの並び順は `lib/features.js` で決める。ここの `label` は **メニューのタイル名と画面の見出しの両方** に使う
- 一覧・集計のカード（やること・合計・記録・進捗度）はそれぞれの画面にしか置かない。あちこちに出ると、どこが本家か分からなくなるため
- 横幅は 752px でそろえ、中身は画面の上下中央に置く。タイトル画面だけカード列が 830px
- **経過時間は `App.jsx` で1秒ごとに数え直し**、計測・メニュー・タイトルに同じ値を渡す。画面ごとにタイマーを持たないので、どこで見ても同じ秒数になる

**記録まわり**

- **集計は保存せず、記録から毎回計算する**。合計値を別に持つと、記録を消したときにずれるため
- **記録の追加は `App.jsx` の `addRecord` 1か所に集める**。計測でも手入力でも同じ場所を通る
- **科目を消しても記録は消さない**。積み上げた時間まで失われるほうが困るため
- **休憩は集計に入れない**。勉強時間に休憩が混ざると、記録として使えなくなるため
- **1日の上限（24時間）は `lib/dayLimit.js` で判定する**。どの日の記録かは `startedAt` の日付で決める

**自信と進捗度まわり**

- **自信は記録ではなく科目に持つ**。「その回の出来」ではなく「科目にどれくらい自信があるか」なので、科目の属性にしておけば比較が単純になる
- **自信の書き換えは `App.jsx` の `setSubjectConfidence` 1か所に集める**。停止時の問いかけでも科目画面の手直しでも同じ場所を通るので、どちらからでも履歴が残る
- **停止直後の自信チェックは保存しない**。開き直したら聞き直さない。記録はすでに残っているので、答えなくても困らないため
- **進捗度の計算はすべて `lib/confidence.js` に置き、科目と記録から毎回計算する**。自信を直した瞬間に、差とおすすめが変わるため
- **混ぜた進捗度は保存せず、`App.jsx` で毎回 `withBlendedConfidence` にかけて渡す**。表示・優先度はこの一覧を、自信の入力は元の一覧を使う。保存すると、重みを変えたときに古い値が残ってしまうため
- **やることリストは科目登録時に必須にしない**。最初に項目を考えるのが一番の壁なので、あとから足せるようにしておく
- **削除の確認は科目だけに出す**。やることの項目は書き直せばすぐ作り直せるので確認しない
