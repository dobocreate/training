# STUDY LOG（勉強記録）

科目ごとの勉強時間を計測して、積み上げを見えるようにするアプリ。
React + Vite で作っていて、データはブラウザの localStorage に保存する。

---

## 1. 動かし方

```bash
npm install   # 初回のみ
npm run dev   # 表示されたURL（http://localhost:5173）を開く
```

| コマンド | 何をするか |
| --- | --- |
| `npm run dev` | 開発用サーバーを起動する |
| `npm run build` | `dist/` に本番用ファイルを出力する |
| `npm run preview` | `build` した結果をローカルで確認する |
| `npm run lint` | oxlint でコードをチェックする |

同じPCで `todo` アプリも動かすときは、ポートをずらす。

```bash
npm run dev -- --port 5176
```

## 3. できること

| メニュー | できること |
| --- | --- |
| 計測 | 科目を選んで開始・一時停止・停止。停止すると記録に残り、今の自信（%）を聞く。遅れている科目を優先して勧める |
| 合計 | 今日・今週・全期間の合計と、科目別の内訳、直近7日の棒グラフ。記録の一覧もここで、削除・編集ができる |
| やること | 科目ごとのやることチェックリスト。できたらチェックすると、その割合が自信に混ざる |
| 自信 | 科目ごとの自信をくらべて、次にやる科目を勧める。自信の手直しと計算の重みの設定もここ |
| 科目 | 科目の登録・削除。名前・自信（0〜100%）・好き嫌い（★1〜5）・色を決めて登録する |

### 計測

- 科目を選んで **開始**。**一時停止** すると休憩として数え、**停止** すると記録になる
- 計測したまま別の画面に移っても止まらない。ブラウザを閉じても続きから再開できる
- 8時間を超える計測は止め忘れの可能性があるので、記録するか破棄するかを確認する
- 休憩の時間は記録に残るが、勉強時間の合計には入れない
- **停止すると「自信チェック」** が計測パネルの上に出る。スライダーか数字で 0〜100% を付けて保存する。閉じるボタンは無く、保存するまで出たままになる
- その科目に未チェックの「やること」があれば、3つまで「今日できるようになった？」と並ぶ。チェックして保存すると、リストにも反映される
- 科目のチップは **やるべき順**（自信画面の「次はこれ」と同じ。横並びなら底上げモードの順）に並び、自信が付いている。開いたときはその先頭の科目が選ばれている
- 先頭より遅れている科目を計測中は「追い上げ中」と出る

### 自信

#### 自信の数値化

自信は「自分の感覚（自己申告）」と「やることリストのチェック率」を混ぜた数字。感覚だけだと日によってぶれるので、根拠を足す。

- 自信 = 自己申告 × 感覚の重み + チェック率 × （100 − 感覚の重み）。重みは **自信の計算** のカードのスライダーで決める（初期値 50%）
- リストが無い科目は自己申告そのまま。項目が 5 個未満の科目は、チェック率の重みを（項目数 ÷ 5）倍に弱める。少ない項目で数字が振れすぎないため
- 追いつきカードの科目ごとに「やること 3 / 10」を添える。自己申告がチェック率より 25% 以上高ければ「自信のわりに、できたことがまだ少ないかも」と一言出す
- 「次はこれ」の下に、その科目の未チェックの項目を1つ出す。「まずは「因数分解」から」
- 混ぜた自信は表示と優先度の計算に使う。自己申告の入力欄（科目画面・自信チェック・自信を直す）は、自己申告そのもの

**追いつき** のカードで科目ごとの自信をくらべ、いちばん自信のある科目（先頭）に他の科目が追いつくよう勧める。

- 科目を自信の高い順に並べ、棒で自信を出す。先頭の位置に青い実線を引き、そこまでの差を「あと ○%」で添える
- **目標の線**（青い点線）を 100% の位置にいつも引く（`GOAL`）。横並びのときの「あと ○%」は 100% までの残り
- **次はこれ**: 優先度が高い → 直近7日で触っていない → 一覧の並び順、で1つ選ぶ。「これにする」で計測の科目に入る
- **優先度** = 先頭との差（%）に好き嫌いのぶんを足し引きしたもの。★1 は +20、★2 は +10、★3 は 0、★4 は −10、★5 は −20。「好きで自信が無い」より「嫌いで自信が無い」を先にするため。星1つぶんの量は `lib/confidence.js` の `FEELING_STEP`
- **差があるときは、平均 80% 以上になったら好き嫌いの足し引きをやめ、差だけで勧める**。しきい値は `RAISE_ALL_FROM`
- ★2以下の科目を勧めるときは「嫌いな ○○」と文言が変わる
- **横並び**: 最大の差が 5% 以内になったら、差では選べないので嫌いな科目から順に自信を上げていく（平均が高くても同じ）
  - 「次はこれ」は ★の少ない科目 → 直近7日でいちばん触っていない科目 → 並び順
  - 文言は「横並び！100% を目指して、まずは嫌いな ○○ から！」。全科目 100% なら好きにやるよう促す
  - 横並びのしきい値は `lib/confidence.js` の `LEVEL_THRESHOLD`
- **自信を直す**: 科目ごとに自信（自分の感覚）と好き嫌いの星を直せる
- **自信の計算**: 感覚 ←→ リスト のスライダーで重みを決める。今の式と、どちら寄りかの一言を出す

### 合計

- 今日・今週・全期間で切り替える
- 科目別の内訳と、直近7日の棒グラフを出す。休憩の合計も横に添える
- その下に **記録** の一覧。日付ごとにまとめ、1件ずつ科目・日付・時間を編集でき、削除もできる。1日の合計が24時間を超える編集はエラーになる

### やること

- 科目ごとに「二次方程式を解けるようにする」のような項目を足し、できたらチェックする。1つの単元・1つの技能を1項目にする
- 科目名の横に「3 / 10（30%）」。チェックした割合が自信に混ざる（「自信」の「自信の数値化」）
- チェックしてから30日以上経った項目は薄く出す。まだできるか見直すきっかけにするため
- 科目を削除すると、その科目のリストも消える（確認のときに件数を出す）
- **1日の合計は24時間まで**。計測の停止は残りぶんに切り詰める

### 科目

- 追加・削除できる。色は8色から選ぶ
- 登録するときに **名前・自信・好き嫌い・色** を決める。自信はスライダーか数字で 0〜100%（ふつうは低めから始める）。好き嫌いは ★1〜5（★1 大嫌い / ★2 嫌い / ★3 ふつう / ★4 好き / ★5 大好き）
- 一覧の数字と星を直せば、自信と好き嫌いをあとから手直しできる
- 自信の付け直しは履歴に残る（`study.confidenceLog`）


- **削除しても記録は消えない**。「（削除された科目）」として一覧と集計に残る

### 自信（タイトル画面）

- 科目を自信の高い順に並べ、棒と % と好き嫌いの星で出す。先頭には「先頭」タグ、遅れている科目の % は黄色
- 先頭の位置に青い実線、目標（100%）の位置に青い点線を引く
- 横並びのときだけ、見出しの横に「横並び！100% を目指そう。まずは ○○ から」を添える。差があるときは棒と線で分かるので文は出さない

### 連続日数（タイトル画面）

- 今日から1日ずつさかのぼって、記録のある日が何日続いているかを数える
- 今日まだ記録が無いときは昨日を起点にする。その日のうちに勉強すれば途切れないため
- 0日のときは「なし」と出す

## 4. データの保存先と注意

保存先はブラウザの localStorage だけ。サーバーには何も送らない。
次のどれかで **データは消える**。

- ブラウザの「閲覧データを削除」
- 別のPC・別のブラウザで開く
- シークレットウィンドウで使う

書き出し・読み込みの機能は持っていない。

## 6. 開発者向けメモ

### 画面の組み立て

- 今どの画面かは `App.jsx` の `screen` 1つで持つ。`"title"` → `"menu"` → 機能のキー、と値が変わる
- メニューの並び順は `lib/features.js` で決める。5つなので1行3つで2行目が2つになる。狭い画面では小さくして1行4つに詰める
- 各機能の画面は、その機能のカードを先頭に置き、操作を助ける小さいカードをそえる

  | 画面 | 並べるカード |
  | --- | --- |
  | 計測 | （自信チェック）→ 計測 → 今のペース |
  | 合計 | 合計 → 記録 |
  | やること | やることチェックリスト |
  | 自信 | 追いつき → 自信を直す → 自信の計算 |
  | 科目 | 科目 → 科目別の累計 |

- 一覧・集計のカード（やること・合計・記録・追いつき）はそれぞれの画面にしか置かない。あちこちに出ると、どこが本家か分からなくなるため
- 横幅は 752px でそろえ、中身は画面の上下中央に置く。タイトル画面だけカード列が 830px

### データの形

- 科目: `{ id, name, color, confidence, feeling }`
  - `confidence` は 0〜100 の整数。`feeling` は 1〜5 の整数（★の数）
  - 前に保存された科目に無いときは、`loadSubjects` が自信 0・好き嫌い ★3（ふつう）を補う
- 自信の履歴: `{ id, subjectId, value, at }`。科目には今の値だけを持ち、推移はこちらで追う
- やること: `{ id, subjectId, text, done, doneAt, createdAt }`。`doneAt` は最後にチェックした時刻（外すと null）
- 設定: `{ selfWeight }`。自己申告の重み（0〜100）
- 記録: `{ id, subjectId, seconds, breakSeconds, startedAt }`
  - 科目は名前ではなく **id で参照** する。科目名を変えても記録が壊れない
  - `breakSeconds` が無い古い記録は 0 として扱う
- 計測中: `{ subjectId, startedAt, accumulated, since, breakAccumulated, pausedAt }`
  - 勉強 … `accumulated + (now - since)`。一時停止で `accumulated` に畳み、`since` を null に
  - 休憩 … `breakAccumulated + (now - pausedAt)`。再開で `breakAccumulated` に畳み、`pausedAt` を null に
  - `since` と `pausedAt` は必ずどちらか片方だけが入る
- 日付は `YYYY-MM-DD` の文字列。文字列のまま大小比較できるので、「今週かどうか」の判定が単純になる（`toISOString()` はUTCになるので使わない）

### localStorage のキー

| キー | 中身 |
| --- | --- |
| `study.subjects` | 科目の一覧 |
| `study.records` | 記録の一覧 |
| `study.running` | 計測中の状態 |
| `study.confidenceLog` | 自信の付け直しの履歴 |
| `study.skills` | やることチェックリスト |
| `study.settings` | 設定（自己申告の重み） |

古い形式（`study.boss` / `study.bosses`、`accumulated` の無い計測状態）は読み込み時に `storage.js` が読み替える。

### 設計の判断

- **集計は保存せず、記録から毎回計算する**。合計値を別に持つと、記録を消したときにずれるため
- **経過時間は `App.jsx` で1秒ごとに数え直し**、計測・メニュー・タイトルに同じ値を渡す。画面ごとにタイマーを持たないので、どこで見ても同じ秒数になる
- **科目を消しても記録は消さない**。積み上げた時間まで失われるほうが困るため
- **休憩は集計に入れない**。勉強時間に休憩が混ざると、記録として使えなくなるため
- **記録の追加は `App.jsx` の `addRecord` 1か所に集める**。計測でも手入力でも同じ場所を通るので、どちらから足しても同じように色が付く
- **トロフィーの到達日**は、記録を日付の古い順に積み上げて、しきい値を超えた時点の日付を割り当てる。1日で2段階超えることもあるので、超えたぶんだけ進める
- **1日の上限（24時間）**は `lib/dayLimit.js` で判定する。手入力と編集は理由の文言を返してフォームに出し、計測の停止は残りぶんに切り詰めて alert で伝える。どの日の記録かは `startedAt` の日付で決める
- **自信は記録ではなく科目に持つ**。「その回の出来」ではなく「科目にどれくらい自信があるか」なので、科目の属性にしておけば比較が単純になる
- **自信の書き換えは `App.jsx` の `setSubjectConfidence` 1か所に集める**。停止時の問いかけでも科目画面の手直しでも同じ場所を通るので、どちらからでも履歴が残る
- **停止直後の自信チェックは保存しない**。開き直したら聞き直さない。記録はすでに残っているので、答えなくても困らないため
- **追いつきの計算はすべて `lib/confidence.js` に置き、科目と記録から毎回計算する**。自信を直した瞬間に、差とおすすめが変わるため
- **混ぜた自信は保存せず、`App.jsx` で毎回 `withBlendedConfidence` にかけて渡す**。表示・優先度はこの一覧を、自己申告の入力は元の一覧を使う。保存すると、重みを変えたときに古い値が残ってしまうため
- **やることリストは科目登録時に必須にしない**。最初に項目を考えるのが一番の壁なので、あとから足せるようにしておく
- **削除の確認**は科目だけに出す。やることの項目は書き直せばすぐ作り直せるので確認しない
