# STUDY LOG（勉強記録）

科目ごとの勉強時間を計測して、積み上げを見えるようにするアプリ。
React + Vite で作っていて、データはブラウザの localStorage に保存する。

---

## 1. 動かし方

```bash
npm install   # 初回のみ
npm run dev   # 表示されたURL（http://localhost:5173）を開く
```

| コマンド | 何をするか |
| --- | --- |
| `npm run dev` | 開発用サーバーを起動する |
| `npm run build` | `dist/` に本番用ファイルを出力する |
| `npm run preview` | `build` した結果をローカルで確認する |
| `npm run lint` | oxlint でコードをチェックする |

同じPCで `todo` アプリも動かすときは、ポートをずらす。

```bash
npm run dev -- --port 5176
```

```
タイトル ──START / Enter──> メニュー ──タイルを押す──> 各機能の画面
                              ^                             |
                              └──「メニューに戻る」/ Esc ────┘
```

- **タイトル**: 今日の勉強時間・連続日数・トロフィーの段階・目標の達成度と、直近7日の棒グラフ。計測中なら経過時間も出る
- **メニュー**: 枠で囲んだパネルに6つのタイルを並べる。計測中は経過時間、目標があれば達成度がバッジで出る

## 3. できること

| メニュー | できること |
| --- | --- |
| 計測 | 科目を選んで開始・一時停止・停止。停止すると記録に残る |
| 合計 | 今日・今週・全期間の合計と、科目別の内訳、直近7日の棒グラフ |
| 記録 | 日付ごとの一覧。編集・削除・手入力での追加ができる |
| トロフィー | 累計時間に応じて9段階のトロフィーを集める |
| 目標 | 期限と時間を決めて、達成度を追いかける。複数持てる |
| 科目 | 科目の追加・削除。色は8色から選ぶ |

### 計測

- 科目を選んで **開始**。**一時停止** すると休憩として数え、**停止** すると記録になる
- 計測したまま別の画面に移っても止まらない。ブラウザを閉じても続きから再開できる
- 8時間を超える計測は止め忘れの可能性があるので、記録するか破棄するかを確認する
- 休憩の時間は記録に残るが、勉強時間の合計には入れない

### 合計

- 今日・今週・全期間で切り替える
- 科目別の内訳と、直近7日の棒グラフを出す。休憩の合計も横に添える

### 記録

- 日付ごとにまとめて表示。1件ずつ科目・日付・時間を編集でき、削除もできる
- 計測し忘れたぶんは **手入力** で、日付と時間を指定して後から足せる
- 足したぶんは色が付き、見える位置まで自動でスクロールする

### トロフィー

累計の勉強時間で段階が決まる。9段階を 3×3 の棚に並べ、到達したものから金色になる。

| 段階 | 必要な累計 | | 段階 | 必要な累計 |
| --- | --- | --- | --- | --- |
| スタート | 0時間 | | 上級 | 80時間 |
| 入門 | 5時間 | | 熟練 | 150時間 |
| 初級 | 15時間 | | 達人 | 250時間 |
| 中級 | 40時間 | | 名人 | 400時間 |
| | | | 極み | 600時間 |

- **到達ずみ**: 金色のトロフィーと、到達した日
- **いまの段階**: 青い枠で光り、バッジの外周リングで次までの進み具合を出す
- **未到達**: グレーの鍵と「◯時間で解放」

### 目標

- 期限・時間・対象科目を決めて設定する。「すべての科目」も選べる
- **決めたあとの勉強だけ** が数えられる
- 残り時間と、期限に間に合わせるために必要な「1日あたりの時間」を出す
- 目標に届くと **達成**、届かずに期限を過ぎると **期限切れ**
- いくつでも同時に持てる。期限が近い順に並ぶ

### 科目

- 追加・削除できる。色は8色から選ぶ
- **削除しても記録は消えない**。「（削除された科目）」として一覧と集計に残る

### 連続日数（タイトル画面）

- 今日から1日ずつさかのぼって、記録のある日が何日続いているかを数える
- 今日まだ記録が無いときは昨日を起点にする。その日のうちに勉強すれば途切れないため
- 0日のときは「なし」と出す

## 4. データの保存先と注意

保存先はブラウザの localStorage だけ。サーバーには何も送らない。
次のどれかで **データは消える**。

- ブラウザの「閲覧データを削除」
- 別のPC・別のブラウザで開く
- シークレットウィンドウで使う

書き出し・読み込みの機能は持っていない。

```
    ├── Milestones.jsx         トロフィーの棚
```

## 6. 開発者向けメモ

### 画面の組み立て

- 今どの画面かは `App.jsx` の `screen` 1つで持つ。`"title"` → `"menu"` → 機能のキー、と値が変わる
- メニューの並び順は `lib/features.js` で決める。6つなので1行3つ・2行に収まる。狭い画面では小さくして1行4つに詰める
- 各機能の画面は、その機能のカードを先頭に置き、操作を助ける小さいカードをそえる

  | 画面 | 並べるカード |
  | --- | --- |
  | 計測 | 計測 → 今のペース → 追加した記録 |
  | 合計 | 合計 |
  | 記録 | 記録 → 手入力で追加 |
  | トロフィー | トロフィー |
  | 目標 | 目標 → 今のペース → 追加した記録 |
  | 科目 | 科目 → 科目別の累計 |

- 一覧・集計のカード（記録・合計・トロフィー）はそれぞれの画面にしか置かない。あちこちに出ると、どこが本家か分からなくなるため
- 横幅は 752px でそろえ、中身は画面の上下中央に置く。タイトル画面だけカード列が 830px

### データの形

- 記録: `{ id, subjectId, seconds, breakSeconds, startedAt }`
  - 科目は名前ではなく **id で参照** する。科目名を変えても記録が壊れない
  - `breakSeconds` が無い古い記録は 0 として扱う
- 計測中: `{ subjectId, startedAt, accumulated, since, breakAccumulated, pausedAt }`
  - 勉強 … `accumulated + (now - since)`。一時停止で `accumulated` に畳み、`since` を null に
  - 休憩 … `breakAccumulated + (now - pausedAt)`。再開で `breakAccumulated` に畳み、`pausedAt` を null に
  - `since` と `pausedAt` は必ずどちらか片方だけが入る
- 目標: `{ id, name, deadline, targetHours, subjectId, createdAt }`。配列で持つ
- 日付は `YYYY-MM-DD` の文字列。文字列のまま大小比較できるので、「今週かどうか」の判定が単純になる（`toISOString()` はUTCになるので使わない）

### localStorage のキー

| キー | 中身 |
| --- | --- |
| `study.subjects` | 科目の一覧 |
| `study.records` | 記録の一覧 |
| `study.running` | 計測中の状態 |
| `study.goals` | 目標の一覧 |

古い形式（`study.boss` / `study.bosses`、`accumulated` の無い計測状態）は読み込み時に `storage.js` が読み替える。

### 設計の判断

- **集計は保存せず、記録から毎回計算する**。合計値を別に持つと、記録を消したときにずれるため
- **経過時間は `App.jsx` で1秒ごとに数え直し**、計測・メニュー・タイトルに同じ値を渡す。画面ごとにタイマーを持たないので、どこで見ても同じ秒数になる
- **科目を消しても記録は消さない**。積み上げた時間まで失われるほうが困るため
- **休憩は集計に入れない**。勉強時間に休憩が混ざると、記録として使えなくなるため
- **記録の追加は `App.jsx` の `addRecord` 1か所に集める**。計測でも手入力でも同じ場所を通るので、どちらから足しても同じように色が付く
- **「追加した記録」は追加した順**で並べる。日付順にすると、過去の日付を手入力したときに今足したぶんが埋もれるため
- **トロフィーの到達日**は、記録を日付の古い順に積み上げて、しきい値を超えた時点の日付を割り当てる。1日で2段階超えることもあるので、超えたぶんだけ進める
- **目標の達成度**（`goalProgress`）はタイトル画面とメニューの両方に出す。複数あるときは期限が近い1件を代表にして「ほか◯件」を添える
- **削除の確認**は科目だけに出す。記録と目標は決め直せばすぐ作り直せるので確認しない
