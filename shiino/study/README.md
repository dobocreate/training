# shiino_勉強記録

React + Vite で作った、科目ごとの勉強時間を記録するアプリ。

## 起動方法

```bash
npm install   # 初回のみ
npm run dev   # 表示されたURLを開く
```

他のアプリと同時に動かすときは `npm run dev -- --port 5176` のようにポートを指定する。

## できること

- **計測**: 科目を選んで開始／停止。停止した時点で記録に残る
- **手入力**: 計測し忘れた分を、日付と時間を指定して後から追加
- **科目の管理**: 追加・削除。色を8色から選べる
- **合計**: 今日／今週／全期間で切り替え。科目別の内訳を棒グラフで表示
- **直近7日**: 日ごとの勉強時間を棒グラフで表示
- **記録の一覧**: 日付ごとにまとめて表示。1件ずつ削除できる

## データの保存

ブラウザの localStorage に保存する。サーバーは使っていないので、

- リロードしても消えない
- 同じブラウザの同じサイト（オリジン）でだけ見える。別のPCやブラウザには引き継がれない
- ブラウザのデータを消すと、記録も消える

保存しているキーは `study.subjects` / `study.records` / `study.running` の3つ。

**計測中にページを閉じても大丈夫**。開始時刻を保存しているので、開き直すと計測が続いている状態から再開する。
経過時間は「今の時刻 − 開始時刻」で出しているため、タブを裏に回してもずれない。

## ファイル構成

```
src/
├── App.jsx                    全体の状態（科目・記録・計測中）と操作
├── App.css                    見た目
├── index.css                  背景（星・星雲）と共通の色
├── main.jsx                   Appを画面に描画する入口
├── lib/
│   ├── time.js                時間・日付の計算と表示形式
│   └── storage.js             localStorage の読み書き
└── components/
    ├── Timer.jsx              計測（科目選択・開始／停止）
    ├── ManualEntry.jsx        手入力での追加
    ├── SubjectManager.jsx     科目の追加・削除
    ├── Summary.jsx            合計・科目別の内訳・直近7日
    └── RecordList.jsx         記録の一覧・削除
```

## 設計のメモ

- 記録は `{ id, subjectId, seconds, startedAt }` の形。科目名ではなく **id で参照**しているので、
  科目名を変えても過去の記録が壊れない。
- 集計は保存せず、記録から毎回計算する。合計値を別に持つと、記録を消したときにずれるため。
- 日付は `YYYY-MM-DD` の文字列で扱う。この形式なら文字列のまま大小比較でき、
  「今週かどうか」の判定が単純になる（`toISOString()` はUTCになるので使っていない）。
- 科目を削除すると、その科目の記録もまとめて消える。消える件数を確認ダイアログで伝えてから実行する。
